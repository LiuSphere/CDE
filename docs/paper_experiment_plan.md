## 1. 目标与固定范围

当前主方法为全连接注意力 mixer、无交叉的 `gavdac_ea_main`，定义见
[算法配置说明](../src/config/algs/README.md)。
保留种群选择、精英/父代继承、变异、种群经验回放及 RL 注入。
不改变环境、奖励、设备约束、源 CSV、网络尺寸及现有主方法的学习更新规则。

本轮正式实验回答：

1. 相比规则调度、纯 GAVDAC 和独立多智能体基线，主方法的经济性、稳定性与计算代价如何？
2. 无交叉前提下，EA 整体的收益和额外训练代价是多少？
3. 连续跨天 SOC 下，节约是否仍成立，物理约束和库存变化是否可解释？

不设置无变异、去交叉、星形邻接、网络结构或 RL 注入消融，不扫描交叉概率。
因此不能单独归因于变异、attention、图拓扑或专用架构，
也不能将未参与训练的奖励分解描述为已验证机制。
MAPPO 是整体算法对照，不是架构单因素消融；不预设主方法必胜。

## 4. 先冻结统一评估协议

遵守[实验评估与溯源约定](paper_execution.md)，在新增正式训练和比较评估前：

1. 核实并冻结0基行索引：训练行0至730，验证开发行731至912，
   checkpoint 选择固定行731至738，最终保留评价行913至1094，共182天。
   核对当前数据长度、索引语义和实际加载逻辑，不臆称自然日期。
   checkpoint 以初始 SOC 0.35、每日独立重置的固定8日平均验证回报选择；
   保持统一评价频率，不无说明地扩大为全验证时段选模。
2. 展示候选日不是独立测试，也不替代整个固定评价时段。
   当前保留时段曾用于诊断，不能称为未触碰测试集；
   全部重新训练不会改变数据使用历史，本轮只能称为回顾性保留评价。
   真正独立的外部验证需另获未使用数据，不从验证日重新贴标签。
3. 主经济性评估使用上述全部182天，各方法以三个电池 SOC 均为0.35开始，
   按相邻行顺序传递各自末端 SOC。终端 SOC 在设备边界内自由，不强制每日闭合，
   不修改训练奖励。另报同日期、SOC 每日重置为0.35的版本，不能混合比较。
   主经济性指标为全时段 `economic_cost`，同时报告 `full_cost`，不将后者统称货币支出。
   原始成本、期末库存及库存敏感性诊断分别报告，不将绝对 SOC 偏差修正称为终端价值。
4. 主表固定使用验证集选出的 RL Actor；EA Actor 单列补充，禁止逐日选优。
   只用验证集选 checkpoint、规则阈值和预登记范围内的 MAPPO 参数。
5. 所有学习组统一数据、交互预算和评价频率；记录局部观测、集中 critic 信息及循环历史。
   连续评价仅传递物理 SOC，循环 Actor 隐状态和前一动作输入每日重置，
   保持既有每日 episode 语义，C1/C2/C3边界一致；不宣称全部策略记忆连续182天。
   runner 调用 `init_hidden()` 和 `select_actions(batch, t_ep, t_env, test_mode)`；
   MAPPO 适配这一接口或经验证的等价路径，不把环境 `dispatch()` 当策略接口。
   观测、状态、动作维度从环境接口读取并检查，不硬编码；actor 的信息边界一致。
   不能强行照搬 GAVDAC 更新规则给 MAPPO；算法差异及实际训练量必须披露。
6. 审计总步数是否覆盖 EA rollout，同时记录梯度更新次数、EA 代数、策略评估次数和墙钟时间。
   同环境步不代表相同外生日覆盖或计算量。种子标签不等于严格配对复现。

规则只可使用当前观测、可得价格和环境已有4小时因果预测特征，
不读取未来实际负荷或光伏；仅在训练/验证数据开发，阈值和优先级在查看保留结果前冻结。
MILP 核对 `tools/run_physical_microgrid_milp.py` 与当前模型的成本及设备约束，
主参考以相同连续时段、共同起始库存和自由末端 SOC 为目标，
披露预测与求解时域、完美预测优势、求解状态、时限、gap及分段近似误差。
连续入口 `tools/run_continuous_microgrid_milp.py` 明确最小化主货币指标
`economic_cost`，同时从回放报告 `full_cost`，不将货币目标的界称作综合成本下界。
旧逐日工具保留默认综合成本目标，不能混作同一参考。
每日循环 SOC 的 MILP 如需保留，另列参考，不作为非循环 RL 的严格成本下界。
连续评价、规则和 MAPPO 的工具能力均需先检查，未实现的部分不能标为已具备。

逐步轨迹重算成本分项和全时段汇总，与本轮环境输出核对；
连续版不要求等于日重置版。P0不依赖历史模型，不运行正式保留集比较。

不静默降级，不把滚动参考称作全时段最优解。只有成本、约束、库存和求解证据匹配时，

## 6. 结果与最终验收

最低交付：

1. 主对比表：C0至C4，列全时段货币成本 `economic_cost`、
   综合成本 `full_cost`、库存及物理约束结果；MILP 明确标为理想信息参考。
2. EA整体对照表：C1/C2，列每个种子、均值/标准差、最差日、交互与更新量和训练时间；
   不列无变异或重复的去交叉组。
3. 固定验证曲线：横轴含 EA 的累计总交互步，展示3个种子的波动，
   披露对齐或插值方式，不将末端正斜率等同于完全收敛。
4. 全时段成本分项、购电/发电/互济/弃光、充放电及初末 SOC；
   分别检查 SOC、设备功率、互济功率、能量平衡和 SOC 转移。
5. 按外生负荷/光伏等规则预先选定的共同代表日，从连续轨迹截取并标注初末 SOC；
   最优日展示只作补充，不替代全时段结果。

节约率统一为 `1 - 方法总成本 / 规则总成本`，其他分母另列。
先按种子汇总整个固定时段，再跨种子统计，不把连续日当成独立训练重复。
P0在查看本轮保留结果前登记实际有意义的改善阈值和统计计算方式，
同时报告效应大小、全部种子和波动，不用“差距小于一个标准差”机械裁决。
本轮预登记实际改善阈值为全时段货币成本均值下降至少1%，同时逐种子报告方向：
C2/C0需3个种子均降低成本；C2/C1按同种子标签列差值并检查3次方向一致，
但不把标签视为严格配对随机过程。此阈值仅为实际意义与有限一致性判断，
不是统计显著性标准；均值、样本标准差（ddof=1）及全部原始结果必须同时报告。
三种子只提供有限稳定性证据；差异不能稳定支持改善时报告“未见可靠优势”。
逐日差值用于解释场景，不夸大独立重复数量；关闭探索并验证重复执行一致性，
未经检查不宣称评价完全确定。
与规则比较仅说明相对该规则的收益；与 MAPPO 比较不能单独证明或否定架构；
与 MILP 的差距结合信息、时域、库存和求解误差解释，不直接归因于网络能力。
电池双向活动是解释指标，不要求吞吐量越大越好，也不把每日 SOC 不闭合判作物理违规。

完成标准为：C1/C2/C3各有3次全新、可追溯的合格完整运行，
连续版与日重置版分别可重建，统一评估及基线证据齐备，
全部主结论可重建且没有测试选模。若 MAPPO 尚未完成，只能报告阶段性结果，
不能把缺少独立多智能体对照或有效 MILP 参考的矩阵称为全部完成。
