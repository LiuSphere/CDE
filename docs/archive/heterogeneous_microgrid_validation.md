# 异构微网与有限互济验证

> 本文保存 `heterogeneous_exchange_v2` 的历史验证。
> 当前为 `facmac_dispatch_v3`，设备与物理约束不变，学习接口改动见
> `docs/facmac_environment_v3.md`。v2 源码由同名版本 tag 保存。

## 结论与范围

本文模型为 `heterogeneous_exchange_v2`，分支为
`codex/microgrid-physical-env`。仍然是三个智能体，每个两个连续动作，
共享一个带智能体 ID 的 RNN 策略。环境不替策略优化发电或电池动作。

本次针对“各智能体只是同比例副本、没有真实协作”的问题进行了修改。
保留物理 v1 的能量方程、正退化成本、SOC 约束、数据切分和 CPU 训练流程。
未修改源 CSV、算法奖励缩放、依赖或旧结果，未进行正式长训练。

**182 个验证日全部通过后冻结参数，182 个测试日也全部通过。**
这说明该场景下电池和互济具有真实的优化价值，不代表 FACMAC 已经学会这些策略。
所有数值是 kW/kWh/CU 实验场景假设，不是真实站点标定或实际货币电费。

## 实际改动

| 项目 | 傍晚负荷型 agent1 | 日间光伏型 agent2 | 灵活供给型 agent3 |
| --- | ---: | ---: | ---: |
| 负荷基础权重 | 0.55 | 0.20 | 0.25 |
| 负荷分配权重峰时 | 20 | 12 | 5 |
| 光伏基础权重 | 0.10 | 0.70 | 0.20 |
| 发电上限 kW | 110 | 50 | 240 |
| 电池容量 kWh | 220 | 180 | 600 |
| 电池额定功率 kW | 70 | 45 | 120 |
| 电池名义时长 h | 3.14 | 4 | 5 |
| 发送/接收功率上限 kW | 160 | 240 | 160 |
| 发电线性成本 CU/kWh | 0.17 | 0.15 | 0.12 |

负荷与光伏分别用平滑的时段权重分配，逐小时总量守恒。
基础权重不等于每日实际能量份额；完整公式、振幅和峰时见
`src/config/envs/microgrid_explained.md`。
三块电池不再与负荷同比例，功率/能量时长也不同。

互济是有节点功率限制的统一损耗运输近似，不是交流潮流。
源端送出 1 kWh，受端总计得到 0.98 kWh；
源端承担 0.003 CU/kWh 输送成本。损耗和费用都进入全队优化。
每小时按动作产生的剩余和缺额等比例撮合，不运行隐藏 MILP，
不读取未来，不允许购电转卖，不允许本站同时发送和接收。
本地动作改变其他微网的购电与成本，独立最优决策不再自动等于联合最优。

当前电价、效率和输送费对所有节点相同，因此固定设备动作后的最大交换量
具有相同全队经济效果；MILP 允许多个等价路由，环境确定性地等比例撮合。
回放核对每小时全队购电、弃电、发送、接收总量，
并逐智能体核对电池功率和 SOC。

观察由 4 维增加到 12 维，全局状态由 12 维增加到 36 维：
增加当前时刻、其他微网当期负荷/PV/可用储能广播，以及本地设备容量。
没有未来预测输入。动作仍为 `[发电比例, 电池比例]`。
这是假设有当前状态广播的合作控制，不是严格无通信控制。

因为供给型微网向外支援时可以超过自身负荷。

全队发电占比 10%-75%、全队购电至少 10%。
电池充放电/SOC、发电活跃小时和光伏利用率门槛没有降低。

## 对照方法

每天运行三个联合 MILP，包含全部三个智能体：

- 完整场景：电池与互济都可用。
- 无互济：仅令三个节点联络上限为零，发电/电池/电网全部重新优化。
- 无电池：仅令充放电功率为零，发电/互济/电网全部重新优化。

比较使用相同输入、设备成本、初始 SOC 和终端 SOC。
无互济不是把完整场景中的线路功率事后删掉。
完整成本包括购电、发电二次成本、排放代理、储能吞吐成本和输送费。
三块电池每天初末 SOC 均为 0.35，不借用免费的初始储能。

发电二次成本使用 32 段凸弦插值。
保留 MILP 状态、间隙、PWL 误差界及精确目标下界，
每个联合解和对照解都在环境中回放。最终输出保存两组对照的调度与证书。
成本收益门槛还使用“本方案精确成本/对照最优成本下界”保守验算，
不只比较两个近似目标值。

日循环是 MILP 参考约束；RL 环境跨天保持 SOC。
因此该日循环参考不是任意非循环策略回报的严格全局上界。

有效电池功率须超过其额定功率的 1%；有效发电须超过额定功率的 5%。
放电比值使用 20%-80% SOC 可用能量乘放电效率，不是全名义容量循环次数。
全部电池日最小放电比值为 1，全部覆盖 0.2-0.8；
没有最低吞吐约束或设备活跃奖励。

共同电价仍会使部分动作同步，这是合理的共同外生信号。
但在 56.11% 的测试小时，至少两个电池的归一化动作相差超过 0.1；
电池动作两两相关系数为 0.65-0.78，而不是同比例复制。
该指标只作描述，不作为调参门槛；MILP 多解也可能影响具体动作序列。

最大完整场景求解/回放差异约为 1.85e-11，
最大单节点功率平衡残差约为 1.28e-13 kW。
互济总损耗严格为发送量的 2%。全部解达到请求间隙并通过 PWL 成本证书。

## 模型边界

没有共享变压器容量约束、交流电压/无功潮流、爬坡、启停或寿命状态模型。
大电网可以补足任意剩余缺额，所以不会人为制造缺电来强迫设备使用。
没有内部电价、业主收益分配、竞价或独立业主参与约束，
这是统一团队成本下的合作问题，而不是经过公平结算证明的电力市场。
若未来引入不同节点电价、不同路径损耗或选择性路由，
当前等比例撮合与 MILP 总目标等价性必须重新验证，不能直接沿用。
