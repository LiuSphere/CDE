# 当前模型的完美预测经济调度

> 历史记录：本文对应 `maenv_sep_v1`，不适用于当前 `facmac_dispatch_v3` 分支。
> 新入口为 `tools/run_physical_microgrid_milp.py`，新说明见
> `docs/facmac_environment_v3.md`。下文保留用于解释旧结果。

独立入口：

```powershell
uv run python tools/run_current_model_milp.py --days 8 --segments 64 --time-limit 30 --gap 0.0001
```

不启动训练、不修改奖励，不覆盖旧模型的 MILP 工具。
输出写入新的 `results/oracle_milp/current_model_<时间>_<随机后缀>/`。
显式 `--output-id` 必须是未使用的目录名。

## 实验口径

- 使用当前 `microgrid.yaml` 的设备参数与环境标准化数据。
- 按现有 `typical_day_rows` 选日期；为空时取测试集中前 8 行，即 913 至 920（零基索引）。
- 这些日期是固定测试样本，不是按四季或统计聚类筛出的代表日。
- 每个日期、每个智能体独立求解 24 小时；未来输入全部已知。
- 每日初始 SOC 为现有评估配置中的 0.35，不增加期末目标或期末惩罚。
- 不把原始 CSV 值重新放回功率平衡；原始值只用于核对和展示。
- 独立计费，不把三台设备合并去供给一份系统负荷。

优化目标是已有经济成本项之和：

```text
购电成本 + 0.5 × 发电成本 + 电池成本
```

排放成本和动作越限惩罚只记录，不参与这个目标。
因此这不是当前强化学习完整奖励的严格上界，也没有新设计奖励。

## MILP 与近似范围

使用 SciPy 的 `milp` 接口调用 HiGHS，不引入新依赖。
五种互斥电池转移对应：正常充电、正常放电、下界投影且实际放电、
下界投影且实际功率为零、上界投影。
每个转移保留旧版 SOC 乘效率公式、请求功率和投影后实际功率的区别。

用二进制变量约束 `import = max(pg, 0)`，不能仅靠正电价下的最小化技巧，
因为当前标准化电价包含负值。
`pb > 0` 时电池成本乘 0.3，其他情况乘 1，照当前模型保留。

发电成本和电池成本的二次函数使用凸分段线性弦插值。
每段长度为 h、二次项系数为 a 时，插值过估计不超过 `a*h*h/4`。
报告同时保存 PWL 目标、回放后的精确经济成本、插值误差和保守误差界。

严格分支另有两个数值近似：

- 正放电功率下限设为 0.001（模型功率单位）。
- SOC 投影的严格越界测试采用 0.000001 的安全间隔。

这会排除原连续模型的微小区域。最优性间隙及成本下界只适用于此受限模型，
不能直接声称获得原始不连续模型的全局最优解。
时限按每个智能体计算，有可行解但未满足间隙时，状态明确标记为未证最优。
若无可用解，脚本报错，不将失败当作零成本。

## 回放与数据

解出的动作送入独立 `MGEnv`，逐小时核对 SOC、实际电池功率和电网功率。
正常转移刚好落在 SOC 边界时，回放可能因浮点误差触发另一条严格分支；
只做约 1e-10 SOC 的向内数值修正，并记录请求功率修正量与回放误差。
若超过容差，脚本停止。

文件包括：

- `typical_day_trajectories.csv`：全部日期、小时、智能体的回放数据。
- `row_<编号>_trajectory.csv`：逐日数据。
- `zero_action_baseline.csv`：相同日期与初始 SOC 的零动作对照。
- `day_summary.csv`：经济成本、遗漏的排放/动作惩罚、间隙、投影次数和末尾 SOC。
- `solver_results.json`：全部求解状态、下界、请求/实际功率与模式。
- `manifest.json`、`config_snapshot.yaml`：实验口径、版本、配置和数据哈希。
- 每日两张 PNG：输入/SOC/成本总览，以及三智能体调度功率图。

模型电价、负荷和光伏均已标准化，成本不具有已核实的货币单位。
微小放电触发 70% 的电池成本折扣、负标准化电价及旧投影规则
可能使优化结果偏向非物理行为；这些行为应先作为模型诊断，
不能直接当作现实电网的节费能力。
