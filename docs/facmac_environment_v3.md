# GAVDAC 微电网环境

当前环境实现为 [`MGEnv`](../src/envs/maenv.py)，标识为 `gavdac_dispatch_v3`。
参数含义和观察索引见[环境配置说明](../src/config/envs/microgrid_explained.md)，
具体数值以[环境 YAML](../src/config/envs/microgrid.yaml)为准。
本文保留旧文件名用于兼容文档导航，不对应一个额外运行版本。

## 调度与物理语义

三个异构微网共享一个带智能体标识的循环策略。每个智能体每小时输出两个连续动作：
发电比例和电池动作；电池功率正值为放电，负值为充电。
电池动作缩放当前 SOC 下的可行功率区间，而不是用不可行请求硬裁剪制造调度。
环境不替策略调用优化器，也不以电池吞吐量越大作为奖励目标。

充电效率乘入储能，放电效率用于计算从电池移出的能量；功率与容量分别受限。
微网互济有节点功率限制、损耗和输送费。kW、kWh、CU 是实验场景单位假设，
不是经站点标定的真实电费或设备测量。

## 观察与奖励

每个智能体有20维局部观察，集中状态为三个局部观察的拼接。
预测特征使用训练数据的小时模板和当前观测修正，不读取未来真实负荷或光伏。
电价输入依赖场景中周期电价提前公布的假设，不能直接套用到未知实时电价。

个体奖励为 `reward_scale * (baseline_cost - full_cost)`，团队奖励为个体奖励均值。
基线依赖外生场景，与策略动作无关；它不是额外储能奖励。
`economic_cost` 与 `full_cost` 分开报告：后者还包含排放代理成本和约束罚项，
不能把它全部称为货币支出。

## 时间与库存

训练按24小时轨迹采样，SOC 可跨天传递。EA 同轮候选从相同日期和初始库存比较，
候选轨迹同样计入训练交互预算并进入回放池。
相同环境步不意味着所有方法覆盖了相同数量的不同日期。

最终展示日单独从固定初始 SOC 运行，与连续多日库存任务不同。
日末 SOC 不闭合不等于物理违规；双向充放电也不等于经济性更优。
跨算法经济比较须说明初末库存和预测信息边界，详见[评估约定](paper_execution.md)。

## 版本与证据

历史 `facmac_dispatch_v3` 检查点保留原标识和源码哈希，应使用其经过核验的源码快照，
不能通过改写 metadata 或取消校验来加载。名称变更不构成新的实验结果。

模型校准曾使用现有保留测试时段，因此不能声称它是历史上从未使用的独立测试集。
相关证据保留在[异构微网验证](archive/heterogeneous_microgrid_validation.md)及
[v3 开发记录](archive/environment_v3_development.md)。
旧版短训练、多种子诊断和 MILP 验证只支持各自记录的范围，不证明当前算法的稳定优势。
