## Code Basis And Conjecture

Restored modules/critic.py maps concatenated original local observation/action
through fc1-ReLU-fc2-ReLU-fc3, without hidden normalization. The learner makes
one online Critic and a deepcopy target before creating its optimizer.
gradient_pool.py explicitly constructs that same learner per worker, transports
its module state/gradients and uses a global valid-transition denominator.
These are code facts, not evidence of unstable activation scales or a bug.

Conjecture: per-sample normalization of both Critic hidden preactivations can
improve optimization of the original one-step mixed-Q regression sufficiently
to meet the frozen economic target. This is a new standalone representation
intervention, not a combination or reversal of H01-H05mechanisms.

Primary sources verified2026-10-23:

- Ba, Kiros and Hinton, Layer Normalization,2016, Section3/Eq3and Section6:
  https://arxiv.org/html/1607.06450v1
  Normalizes across one example's hidden units with learned gain/bias;
  gains1/biases0 are the reported default. This is not a microgrid study,
  and its recurrent-network benefits do not prove benefits for this MLP.
- OpenAI Baselines official common/models.py, mlp(layer_norm=False), optional
  affine -> layer_norm -> activation; DDPGCritic concatenates obs/action
  and calls this network builder. Layer normalization is OPTIONAL, not
  established by the unused Critic.layer_norm attribute alone:
  https://raw.githubusercontent.com/openai/baselines/master/baselines/common/models.py
  https://raw.githubusercontent.com/openai/baselines/master/baselines/ddpg/models.py
  This motivates placement, not a reproduction of its DDPGarchitecture.
- PyTorch official LayerNorm formula/defaults, last-dimension biasedvariance,
  eps1e-5, affinegain1/bias0 and per-input statistics in train/eval:
  https://docs.pytorch.org/docs/2.14/generated/torch.nn.LayerNorm.html
  Use the installed locked PyTorch, not a dependency upgrade to this doc version.

LayerNorm changes the hypothesis class/gradients and may discard useful
absolute amplitude, worsen value fitting/action sensitivity, or add unfavorable
compute/regularization. It is not exact forward equivalence to baseline or
evidence of diagnosed scale instability. No3%promise or speedup claim.

For each flattened (batch,time,agent) Critic input independently:

```text
x = original concatenated observation and replay/policy action
h1 = relu(LayerNorm(fc1(x), last hidden dimension))
h2 = relu(LayerNorm(fc2(h1), last hidden dimension))
q = fc3(h2)
```

weight1/bias0. Retain originalfcweights/biases/initialization/outputlayer.

including both affine parameters in every original soft/hard target update.
