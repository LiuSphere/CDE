## Code Basis And Conjecture

`src/learners/gavdac_learner.py:_critic_loss` computes one-step bootstrapped
mixed-Q TD errors, multiplies by the original valid-transition mask, then
minimizes their squared sum divided by the valid count. The per-residual
derivative grows linearly with its magnitude before the existing global
parameter-gradient norm clipping. Replay contains training-day episodes from
both RL exploration and EA. These code facts justify testing bounded influence
at the per-TD-error level; they do NOT demonstrate harmful outliers, a diagnosed
bug, or a cause of the C2/C3economic gap. H01-H03results do not establish that
cause either. No retained-date/Actor/seed selection motivates this proposal.

Conjecture: reducing the influence of large individual mixed-Q TD residuals
while preserving the original local quadratic scale can improve the resulting
Actor enough to meet the unchanged three-seed3%economic gate.

Primary sources checked2026-10-22:

- Mnih et al., Human-level control through deep reinforcement learning,
  Nature518,529-533(2015), doi10.1038/nature14236. Methods, page7 of the PDF,
  discusses bounded error influence and linear loss outside the unit interval.
  https://storage.googleapis.com/deepmind-media/dqn/DQNNaturePaper.pdf
- PyTorch HuberLoss official API defines the unreduced half-quadratic/linear
  loss with fixed delta. Multiply by2below to preserve this code's MSEscale:
  https://docs.pytorch.org/docs/2.9/generated/torch.nn.HuberLoss.html
  Installed torch2.11.0 functional.huber_loss signature was checked locally.
- Patterson, Liao and White, Robust Losses for Learning Value Functions,
  arXiv2205.08464, explicitly distinguishes semi-gradient error clipping from
  its saddlepoint robust Bellman-error algorithms.
  https://arxiv.org/abs/2205.08464

H04is a semi-gradient TD-regression modification, NOT a reproduction of DQN,
the robust saddlepoint algorithm, or a convergence guarantee. Robust regression
can change the learned value's fixed point and underweight rare costly events.
That is a real risk, especially for economic control. Unit delta is a fixed
conventional engineering choice in the existing reward units, not a tuned
microgrid optimum. No grid or alternate threshold is authorized this round.

## Sole Intervention

Opt-in `scaled_huber_critic: true`, config `gavdac_c2_h04` inherited from main.
For the ORIGINAL masked mixed-Q TD residual e, replace e^2 only with:

```text
phi(e) = 2 * huber_loss(e, 0, reduction="none", delta=1)
       = e^2                 if |e| <= 1
       = 2*|e| - 1           otherwise
```

Same sum and ORIGINAL valid-count denominator, including global normalization
for sharded episodes. For |e|<=1, loss and derivative match MSE; beyond it,
dphi/de=2*sign(e). Do not clamp targets, rewards, observations or environmental
costs. This is not replacement/removal of the existing gradient-norm clip.

Use an explicit independent `HuberGAVDACLearner`, sharing the baseline target,
Actor and history construction through a narrow TD-reduction method.
Missing/false selects original learner and original arithmetic; reject
non-boolean flags. Worker initializer explicitly constructs the same opt-in
learner on each shard. No registry or silently ignored option.

Single Critic+mixer; original Actor every Critic step, targets every complete
update with original tau. Keep live mixer-context and action gradients,
recurrent history, Actor regularizer, optimizer types/LRs/clips, replay,
sampling, EA schedules/noise/width and all frozen conditions unchanged.
Do not restore H01detachment, H02double critic, or H03delayed Actor.
No new random draw; parameter and optimizer-update counts unchanged.
Extra loss/finite diagnostics cost is disclosed, not matched execution time.

Persist successful Actor/Critic/target-update and finite-check counts,
joint/agent/EA completion and diagnostic state; never claim exact replay,
environment/RNG resume or save nonexistent Critic checkpoints.
