## Code Basis And Conjecture

Current `GAVDACLearner._critic_loss` regresses masked mixedQ onto a detached
one-step target `r_t + gamma*(1-d_t)*Q_target(t+1, target_action)`.
Replay stores complete episodes, including successive rewards and final
observations, from both RLexploration and EA. The runner stores true terminal
separately from time-limit endings; the latter currently bootstrap. These
facts make a within-episode multistep target mechanically testable without
changing observations, environment interactions, replay sampling or Actor loss.
They do not diagnose deficient credit assignment or explain prior failures.

Conjecture: exposing the Critic to five observed discounted rewards per TD
target can reduce reliance on immediate bootstrap estimates and improve the
resulting Actor enough to meet the unchanged three-seed economic gate.
Five is fixed before implementation, based on a published reference design;
it is not selected from this campaign's rewards/retained results or a grid.

them or add an off-policy correction. Day-tail returns are shorter, not a
new environment boundary. H01-H04failures prove none of these causal claims.

## Sole Intervention

Opt-in `five_step_critic: true`, config `gavdac_c2_h05`, main inheritance.
Main/H05entry config differs ONLY by name and this boolean. Missing/false
selects original learner/arithmetic in both entry and gradient worker;
non-boolean values raise. No horizon grid or separate configurable N.

For each originally valid transition t, let m be the smaller of5and the
number of consecutive valid transitions remaining, stopping after a true
terminal if encountered. Construct the detached target:

```text
y_t = sum(k=0..m-1) gamma^k * r_(t+k)
      + gamma^m * product(k=0..m-1)(1-d_(t+k)) * V_target(t+m)
V_target(j) = original mixed targetQ from original targetActor/targetCritic/
              targetMixer and targetActor recurrent context at observation j.
```

Stop at the FIRST invalid/padded transition; never read rewards/targets past
that boundary or into another episode/day. Include the terminating reward,
then suppress all later rewards/bootstrap on true termination. At a truncated
nonterminal end, use the last observed next-state targetQ, preserving original
time-limit semantics. Invalid starting transitions contribute zero under the
unchanged original mask. No target/reward clipping, normalization or rescaling.

Use independent explicit `FiveStepGAVDACLearner`. A narrow baseline target
construction hook retains EXACT original one-step arithmetic for baseline;
variant overrides only that target construction. The rest of Critic loss is
original masked squared error / original valid count (or global shard count).
No H04Huber, H02doubleCritic, H03delay, H01context-detach combination.

Actor remains every successful Critic step with original live mixer-context/
action gradients and regularizer. All target networks update each step at
originaltau. Preserve recurrent history, optimizer/clips/LRs, dimensions,
EA/replay/batch sampling, information boundary and interaction accounting.
No new random draw or altered update schedule. Worker initializer explicitly
constructs H05on2learner workers, no registry/ignoredflag/serial fallback.
Additional target construction/finite diagnostics are compute, not free.

Persist actual Critic/Actor/target/finite successful update counts,
checkpoint diagnostic state and h05_completion.json joint/agent/EAcounts.
