## Bounded Review And Primary Motivation

Review exactly three mechanism families, no economic pilot or parameter grid:

- Select signed bounded mixing weights. The actual GraphDec chooses sigmoid
  for its GNN; GINGraphConvolution maps both hypernetwork matrices through
  sigmoid and applies scale0.1 after each contraction; GNN readout does the
  same. For fixed state and Actor-hidden attention, adjacency/aggregation,
  positive weights, leakyReLU/ELU and mean readout make Q_total nondecreasing
  in each supplied local utility. This conditional statement is NOT
  monotonicity in physical actions: hidden-context gradients remain live.
- Defer prioritized episode replay. Schaul et al., ICLR2016, Algorithm1 and
  Section3.4, justify sampling/importance correction in DQN, including a
  discussion of coarser experience units. Here an exact episode priority,
  Huber-compatible signal, Actor correction and duplicate/shard refresh
  contract would all need independent decisions. Do not bolt PER onto H14.
- Defer reward decomposition/local auxiliary supervision. The current learner
  never supplies team_rewards to the mixer; its optional local fractions
  are not an active supervised credit-assignment target. Enabling that API
  alone does not define a justified local learning objective. Do not wire,
  delete or make manuscript claims about that path in H14.

Primary sources read live2026-10-29:

1. Peng et al., FACMAC, NeurIPS2021, Section3.1 and Section5 final paragraphs:
   https://proceedings.neurips.cc/paper_files/paper/2021/file/65b9eea6e1cc6bb9f0cd2a47751a186f-Paper.pdf .
   Actor-critic factorisation need not enforce nonnegative mixing weights.
   Their nonmonotonic variant helps on specifically nonmonotonic tasks but
   is task-dependent and can be worse on harder SMAC tasks.
2. Official authors' repository https://github.com/oxwhirl/facmac identifies
   its implementation family. No particular raw mixer file was verified:
   an attempted guessed qmix_nonmonotonic.py URL returned404. Do not claim
   official code equivalence from that unsuccessful lookup.
3. Schaul et al., Prioritized Experience Replay, arXiv1511.05952v4:
   https://arxiv.org/pdf/1511.05952 . This supports the deferred replay
   mechanism, not a result or necessity for this shared recurrent learner.

Hypothesis: allowing bounded signed utility mixing can improve the inherited
Actor2+Huber policy's economic dispatch at the same physical budget.
It is a primary-motivated representation test, not a diagnosed monotonicity
bottleneck, graph/credit-assignment theorem, FACMAC reproduction or3%promise.
The existing attention/context route might already provide enough flexibility.
Signed weights can increase learning difficulty and reduce beneficial bias.
H06/H13 normalization failures and H10 action-centering outcome remain
negative context, not proof for or against signed hypernetwork weights.
