## One Hypothesis

Conjecture: replacing the single bootstrapped mixed-Q target with the minimum
of two independently learned mixed-Q estimates may reduce harmful estimation
error and improve continuous dispatch enough to meet the frozen3%target.
Current code does not establish that overestimation is the cause of its
economic gap. This is a testable hypothesis, not a bug diagnosis.

Code evidence: restored `src/learners/gavdac_learner.py` has one online
critic/mixer, one corresponding target pair, and a target of
reward + gamma * (1-terminated) * target mixed Q. The Actor maximizes
the first online mixed Q after its critic update.

Primary motivation: Fujimoto, van Hoof and Meger, ICML2018,
"Addressing Function Approximation Error in Actor-Critic Methods",
PMLR80:1587-1596, proceedings.mlr.press/v80/fujimoto18a.html.
The paper's clipped double-critic idea motivates this intervention; this
variant is not full TD3 and is not a claimed reproduction of its results.

## Single Structural Intervention

An opt-in `gavdac_c2_h02` uses two independently initialized critic/mixer
branches and corresponding target branches. They see the same replay batch.
Both regress to the same scalar team target:

`y = reward + gamma * (1-terminated) * min(target_Q1_total, target_Q2_total)`.

Take the minimum AFTER each complete mixer, not independently at agent nodes.
Each branch has its own optimizer and unchanged per-branch learning rate and
gradient-clipping limit. Do not halve either loss or jointly clip both
branches; these would change the effective optimization beyond the design.
Update both critics before the unchanged Actor update. The Actor uses Q1
only, with the original live hidden-context gradient route restored after H01.
Update both target critic/mixer branches with the existing target schedule.
Do not add target action noise, delayed Actor updates or an ensemble Actor.

The single intervention necessarily adds critic parameters and critic
optimizer work. Record parameter counts, actual optimizer updates and time;
equal physical-interaction budgets do not imply equal compute.
Default main/no-EA and C3paths must remain unchanged when the option is absent.
Prefer an explicit separate learner class if it isolates this variant while
sharing existing tensor/input helpers; do not replace the baseline implicitly.

Freeze all other entry-merged main parameters, Actor architecture, environment,
reward, data, action/observation information, EA population/mutation/no-crossover
schedule, replay sampling, validation frequency and6Mjoint budget including EA.
Do not merge the separate multiprocessing branch into this round.
