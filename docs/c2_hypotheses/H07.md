## Code And Primary Basis

Restored GAVDACLearner._critic_loss runs the original recurrent targetActor
over replay histories, clamps its actions to each agent's Box, evaluates one
targetCritic+targetmixer at next states, and forms the original one-step TD.
Actor/mixer context comes from the unperturbed recurrent forward history.
No target-action smoothing is present. This is a code observation, not a
diagnosis of overestimation, sharp Q peaks or economic performance cause.

Primary sources checked live2026-10-23:

- Fujimoto, van Hoof and Meger, ICML2018, Addressing Function Approximation
  Error in Actor-Critic Methods, Section5.3/Eqs13-14 motivates averaging
  target values near target actions. Section6.1 fixes Gaussian std0.2 with
  clipping0.5; Section6.2 explicitly reports that a single component gives
  insignificant improvement in most tested cases. This materially limits
  standalone economic support; it is not evidence for this microgrid.
  https://proceedings.mlr.press/v80/fujimoto18a/fujimoto18a.pdf
- Author's official TD3.py constructor/train: policy_noise0.2/noise_clip0.5,
  independently perturb target actions then clip to valid bounds before
  target evaluation. Its twin critics/delayed policy are NOT adopted here.
  https://raw.githubusercontent.com/sfujim/TD3/master/TD3.py
- OpenAI Spinning Up official TD3 equations distinguish target smoothing
  from rollout exploration and clip each action to its own valid bounds.
  https://spinningup.openai.com/en/latest/algorithms/td3.html

Conjecture: smoothing only the original single mixed-Q bootstrap actions
can regularize local action sensitivity enough to meet frozen economics.
This is not TD3 reproduction or an H02/H03combination. The primary paper's
whole algorithm and locomotion results do not establish standalone benefit.
Smoothing may bias good narrow solutions, alter boundary action means,
increase target variance or worsen microgrid cost. No3%promise.
