## Corrected Code And Primary Basis

The restored MGEnv exposes the SAME dimensionless action Box to all agents:
low [0,-1], high [1,1]. Generator action a0 is a fraction; dispatch converts
it to a0*dg_max. Battery a1 scales SOC-dependent feasible power. The Critic
receives these fractions, NOT kW or heterogeneous per-agent action ranges.
Controller affine scaling, replay and Actor previous-action history retain
these environment-coordinate fractions. This is not a diagnosed bug.

next_review_after_h09_a.json incorrectly described heterogeneous physical
Boxes. Its original bytes remain historical evidence; the explicit correction
is h10_scope_correction_a.json/b.json. Do not carry the erroneous kW/range
conditioning explanation into H10. H09's historical "physical Box" language
also does not mean actual kW tensors in the restored replay.

Conjecture: a centered generator fraction at the local Critic's first affine
layer may improve optimization enough to meet the unchanged economics.
Only one positive-offset channel is affected, already dimensionless and
bounded. Benefit may be negligible or negative. This is not physical-unit
normalization, a convergence result, a diagnosed economic cause or a3%promise.
The affine transformation preserves network function-class capacity if the
first-layer weights/bias are compensated, but H10 must NOT compensate them:
same original parameter draws, different input coordinates and generally
different Q. It changes initialization-induced function and optimization
geometry without changing the initialization routine or parameter count.
